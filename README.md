# Svipe

Мессенджер на жидком стекле: вход и регистрация по коду из письма, чаты, «Избранное», настройки.
Внешних библиотек нет, нужен только Node.js 18 или новее (https://nodejs.org).

## Запуск

```
node server.js
```

Откройте http://localhost:3000. Пока почта не настроена, код входа печатается в окне, где запущен сервер.

## Чтобы коды приходили на почту

1. Заведите аккаунт у почтового сервиса с SMTP (у многих есть бесплатный лимит) и возьмите из него адрес SMTP-сервера, логин и пароль или ключ.
2. Скопируйте `.env.example` в `.env` и впишите `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`.
3. Перезапустите сервер. В консоли появится строка «Почта: SMTP …».

Порт 587 работает через STARTTLS, порт 465 через сразу защищённое соединение. Адрес в `MAIL_FROM` должен быть разрешён у вашего сервиса: обычно нужно подтвердить домен или отправителя. Точные настройки смотрите у самого сервиса, их данные могут меняться.

## Как это работает

- Новый пользователь вводит имя и e-mail, получает 6-значный код, вводит его и попадает на главную страницу.
- Код живёт 10 минут, неверно ввести можно 5 раз, новый код можно запросить раз в минуту.
- На главной странице три части: список чатов, переписка и настройки (профиль, цвет, размытие стекла, звук, выход).
- Чтобы написать другому человеку, нажмите «+» и введите его e-mail или @username. Он должен быть зарегистрирован.
- Новые сообщения приходят сразу, без перезагрузки страницы.
- Каждому новому пользователю создаются чат «Избранное» (заметки для себя) и приветствие от Svipe.

## Звонки
В личном чате вверху справа кнопки «трубка» (голосовой звонок) и «камера» (видеозвонок). Звонок один на один, идёт напрямую между браузерами (WebRTC), а сервер только передаёт сигналы. В чате остаётся запись: длительность, «Пропущенный», «Отклонённый».

- Камера и микрофон работают только на `http://localhost:…` или по **HTTPS**. По обычному `http://IP-адрес` браузер их не даст.
- Бесплатные STUN-серверы уже подключены. Если у кого-то звонок не соединяется (мобильный интернет, офисная сеть), добавьте TURN-сервер в `.env`: `TURN_URL`, `TURN_USER`, `TURN_PASS`.
- Проверить на одном компьютере: два разных браузера (или обычное окно и окно инкогнито), два аккаунта. Один микрофон на два окна иногда не делится — лучше проверять на двух устройствах.

## Публикация в интернете

1. Поставьте перед Svipe прокси с HTTPS (Caddy или nginx). Без HTTPS входить небезопасно.
2. В `.env` включите `COOKIE_SECURE=1` и `TRUST_PROXY=1`.
3. В nginx для `/api/events` отключите буферизацию (`proxy_buffering off;`), иначе сообщения будут приходить с задержкой.
4. Делайте копии файла `data/db.json`: там все пользователи и переписка.

## Что важно знать

- Все данные лежат в одном файле `data/db.json`. Для сотен пользователей этого достаточно, для тысяч лучше перейти на базу данных.
- Сообщения хранятся на сервере в открытом виде, сквозного шифрования нет.
- Пока нет: фото и файлов, групповых чатов, push-уведомлений, удаления аккаунта.
- Поиск по e-mail показывает, что человек зарегистрирован. Если это нежелательно, оставьте поиск только по @username.
- Отправку писем я проверял на тестовом почтовом сервере, с реальными сервисами (Brevo, Gmail и другими) не пробовал. Если письмо не уходит, ошибка печатается в консоль сервера.
